# 简介

Motori是一款视觉小说变换演出编排工具，同时具备一定的Live2D动作与表情编辑能力，专为需求在视觉小说中加入复杂的变换演出、立绘交互、运镜效果、与Live2D演出的配合等的用户而设计。

## 它可以做什么？

- 导入图片立绘与Live2D立绘，并通过容器进行层级的管理、以及引擎中特殊对象和层叠式立绘对象的模拟。
- 编排场景、立绘的变换序列，相机的移动，Live2D立绘的动作表情变换，组合成一段完整的视觉小说场景动画效果。
- 将组合出来的视觉小说场景动画片段生成为支持的目标引擎的指令，在目标引擎中实现对应效果。
- 高度通用、灵活的视觉小说引擎场景与基础变换模拟表达能力。
- 支持为Live2D模型创建新的自定义动作与自定义表情，并导出相应的可由Cubism SDK识别的动作、表情文件。
- 静态查看变换动画过程中任意时点处的高精度场景快照。
- 将自定义Live2D动作表情的编辑与变换动画的编辑融于一体，在两者的结合之下达成更具想象力、更具精度的演出效果。

## 它不可以做什么？

- Motori旨在以一套具备泛用性的模型进行跨视觉小说引擎的通用模拟，这使得它仅对具备跨引擎一致性的基础变换属性提供了演算与编辑。就当前而言，这包括XY轴坐标、XY轴缩放、旋转、不透明度六个属性，以及透视相机系统。对于其他的变换属性，Motori当前暂不支持。 
- Motori并不具备视觉小说引擎的文字、音频等其他能力。我们认为Motori所使用的时间轴式的状态系统高度契合、但也仅仅适合于局部的单一演出场景片段的编排设计，并不适用于视觉小说的其他部分、特别是主演出步进状态管理之上。
