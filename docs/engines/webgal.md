# 引擎 / WebGAL

Motori的WebGAL插件当前基于WebGAL 4.6.5版本进行支持。请确保您的WebGAL引擎版本高于4.5.20，或是基于4.5.20以上版本的定制引擎。

## 坐标系预设

Motori中默认配置了两套WebGAL引擎及其定制引擎的坐标系预设方案。

| 名称 | 文件名 | 说明 |
|------|-------|-----|
| WebGAL(Standard) |00_webgal-standard.json|适配于WebGAL 4.6.x版本原版引擎的标准坐标系配置|
|WebGAL (MyGO Engine v3.1)|50_webgal-mygo-3.1.json|适配于WebGAL MyGO专版引擎v3.1.0及以上版本、使用默认的M_3_1_0坐标系且使用默认的2560x1440分辨率的标准坐标系配置|

## 保留字ID

设置立绘ID时，需注意以下的WebGAL保留字ID：
| ID | 说明 |
| ---| ----|
| stage-main | 主舞台对象。若存在，必须是顶层的、唯一的立绘，且必须是普通类型容器。详见下文说明。|
| bg-main | 背景图片对象。该ID仅能被背景类型图像立绘使用；导出指令时，所有背景类型图像立绘的ID将被视为bg-main。 |

## 容器

以WebGAL作为目标引擎时，容器仅能按照以下范式进行使用，否则可能无法生成对应指令，可能与WebGAL引擎中实际支持的效果产生偏差。

### 主舞台对象

WebGAL中具有一个可作为变换目标的主舞台对象`stage-main`。您可以通过创建一个名为`stage-main`的**普通类型**容器，且置于顶层，将其他**所有立绘**放置在该容器的内部，来模拟WebGAL中的该对象。

### 透传容器

透传容器用于对引擎中作为独立立绘存在的多个立绘进行组合使用。您可以自由的进行使用。

### 层叠式图像/组合式立绘

截至Motori支持的版本，WebGAL尚不存在官方的层叠式图像/组合式立绘实现。

在WebGAL的某些定制引擎中，存在私有化的的组合式立绘定义格式；其往往直接使用了WebGAL的单体立绘相应指令，不具备任何程度的次立绘变换能力。可以使用终末类型容器模拟此类立绘，手动设置容器的虚拟路径为对应私有定义文件在WebGAL立绘资源目录下的路径。

## 过渡算法

在以WebGAL引擎作为目标时，您的变换帧仅应当使用以下的过渡算法类型：

| Motori key | UI 显示名 | WebGAL `ease` |
|---|---|---|
| `''`（空） | 平方渐变(缓入缓出/默认) | `easeInOut` |
| `easeIn` | 平方渐进(缓入) | `easeIn` |
| `easeOut` | 平方渐出(缓出) | `easeOut` |
| `circIn` | 圆形缓入 | `circIn` |
| `circOut` | 圆形缓出 | `circOut` |
| `circInOut` | 圆形缓入缓出 | `circInOut` |
| `backIn` | 起点回弹 | `backIn` |
| `backOut` | 终点回弹 | `backOut` | 
| `backInOut` | 起止回弹 | `backInOut` |
| `bounceIn` | 起点弹跳 | `bounceIn` |
| `bounceOut` | 终点弹跳 | `bounceOut` |
| `bounceInOut` | 起止弹跳 | `bounceInOut` |
| `linear` | 线性 | `linear` | 
| `anticipate` | 预先反向 | `anticipate` | 

## 透视相机

至Motori支持的版本，WebGAL尚不存在官方的透视相机支持。Motori中的透视相机效果将被导出为各个舞台对象的近似指令。这将生成大量的变换指令，降低变换效果精度，并使得相应的生成指令完全无法被用户自行二次编辑。

若要使用透视相机，您仅能挂载在主舞台对象`stage-main`之上。使用透视相机时，`stage-main`容器仍可正常自由进行变换，与透视相机不存在冲突。

请勿启用“透视变形预览”功能。

| 透视相机参数 | 导出支持情况 |
| ----------- | ----------- |
| 平移X | 近似烘焙到各立绘变换 |
| 平移Y | 近似烘焙到各立绘变换 |
| 偏航 | 近似烘焙到各立绘变换/无画面扭曲 |
| 俯仰 | 近似烘焙到各立绘变换/无画面扭曲 | 
| 推拉 | 近似烘焙到各立绘变换 | 
| FOV(初始) | 无导出；仅作为内部烘焙计算基准 |
| FOV(缩放) | 近似烘焙到各立绘变换 |

## 时间轴

**强烈不建议**您将0:00.000作为连续的变换序列的开始点。

推荐您将时间轴开始的一段时间留空，或安置序列开始前的、初始的Live2D动作与表情，用于布置序列开始前的状态，方便编排符合实际的舞台变换序列，以及生成对应的初始登场或初始变换指令。

## Live2D支持

WebGAL支持Live2D Cubism 2模型的显示。

WebGAL支持Live2D Cubism 3-5模型的显示；**WebGAL不支持Live2D Cubism 5.3及以上版本模型的显示，不支持Cubism 5.3及以上版本的Cubism运行时文件。**

WebGAL支持Live2D立绘的显示边界设置。

## 导出指令

### 仅初始登场指令

为选中立绘生成对应的changeFigure和changeBg命令，用于**立绘的入场**。该指令无法改变已入场的立绘或背景的变换参数。

对于无需以变换序列形式进行调整时的Live2D立绘，也可用该模式生成对应的changeFigure命令，控制Live2D动作与表情的切换。

该选项对stage-main是无效的。

### 仅初始变换指令

为选中对象生成一个过渡时长留空的setTransform命令，用于**已入场立绘**的变换参数初始化或默认变换。

### 变换序列

为选中对象生成setTempAnimation命令，changeFigure命令与wait命令的组合。

通过setTempAnimation命令，生成涵盖整个选中时间区间的变换动画序列；指令带有-keep参数，不会被指令的切换打断，如有需要可在WebGAL引擎的编辑器中进行手动移除。

通过changeFigure命令与wait命令的组合，控制Live2D动作与表情的切换序列。注意，这可能会对您在WebGAL引擎中的、同期的其他指令，特别是对话语句的使用产生影响。

变换序列模式**仅对已入场的立绘有效，假定相应对象在执行这些生成的指令前已经入场、且处于序列开始时的状态**。

变换序列模式生成的指令**无法用于立绘入场。**
